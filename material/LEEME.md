# Material de clases

Tirá acá los resúmenes, apuntes, tabs y lo que tengas del profe.
Cualquier formato sirve: .txt, .md, .pdf, .docx, capturas.

Esta carpeta **no se sube a git**: es material de un tercero y se queda
en tu máquina. Solo se versiona este LEEME.

## Qué se usa de acá

1. **Notación de tablatura** — para que la app escriba las tabs como las
   leés vos, no como se me ocurrió a mí.
2. **Escalas y posiciones** — como tercera fuente para contrastar contra
   las tablas de `armonica/tablas.py`, que ya están verificadas por cálculo.
3. **Licks y frases** — material de prueba real para calibrar los umbrales
   de detección, y base del futuro modo "repetí esta frase".
4. **Prioridades pedagógicas** — para que las reglas de fortalezas y
   puntos a trabajar del resumen de sesión digan algo útil.

## Criterio

Si algo de este material contradice las tablas ya verificadas del proyecto,
se marca la diferencia y la decidís vos. No se pisa lo verificado en silencio:
los resúmenes automáticos se equivocan seguido en detalles de teoría.
